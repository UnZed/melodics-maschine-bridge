# Changelog

## 0.1.0

First public preview.

- English macOS app with start, stop, and diagnostic log controls.
- Virtual 4×4 Melodics profile with 16-pad strike and release input.
- Blue and yellow hand cues and white Preview flashes on the Maschine pads.
- Native USB device discovery and local profile setup.
- Physical workflow tested on Maschine+. The public package uses a new pad-grid icon.
